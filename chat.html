ใช้ Open WebUI คุยกับโมเดล

หน้านี้สอนเฉพาะหน้าเว็บแชท การเปิดโมเดลขึ้น RAM อยู่หมวดโมเดล คนละหน้าที่กัน

ขั้นที่ 1 เปิดหน้าเว็บแชท

  1. เปิดเบราว์เซอร์

    บนเครื่อง DGX เปิด Firefox หรือ Chrome จากแถบแอป

  2. คลิกแถบที่อยู่ด้านบนสุด

    ลบข้อความเก่าออกให้หมด

  3. พิมพ์ที่อยู่แล้วกด Enter

    บนเครื่องนี้: http://127.0.0.1:18473

    จากเครื่องอื่นในบ้าน: http://192.168.178.98:18473

  4. ดูว่าขึ้นหน้าไหน
    • ขึ้น Sign in to Open WebUI = ไปขั้นที่ 3
    • ขึ้นช่องแชทตรงกลาง = ล็อกอินอยู่แล้ว ไปขั้นที่ 4
    • หน้าไม่ขึ้น = ไปหมวดแก้ปัญหา

ขั้นที่ 2 สมัครบัญชีครั้งแรก

บนเครื่องนี้สมัครแอดมินไปแล้ว หน้าสมัครถูกปิดอยู่ ไม่ต้องทำซ้ำ เก็บไว้เมื่อติดตั้งใหม่

  1. เข้า http://127.0.0.1:18473 ตอนยังไม่มีผู้ใช้

    คนแรกที่ได้สมัครคือผู้ดูแลระบบ

  2. กรอกชื่อ อีเมล รหัสผ่าน

    ใช้รหัสที่จำได้เอง อย่าแชร์ให้คนนอก

  3. กดสร้างบัญชี

    หลังจากนี้คนอื่นสมัครเองไม่ได้จนกว่าแอดมินจะเปิด signup

ตอนนี้ signup ปิดแล้ว ถ้าลืมรหัสผ่านต้องรีเซ็ตในเครื่อง

ขั้นที่ 3 เข้าสู่ระบบ

  1. คลิกช่อง Email

    พิมพ์อีเมลของบัญชีที่สมัครไว้

  2. คลิกช่อง Password

    พิมพ์รหัสผ่าน คลิกไอคอนตาทางขวาถ้าอยากเห็นตัวอักษรชั่วคราว

  3. ตรวจก่อนกด

    ต้องมีอีเมลและรหัสผ่านครบทั้งสองช่อง

  4. คลิกปุ่ม Sign in
ถ้าขึ้น Invalid credentials แปลว่ารหัสหรืออีเมลผิด อย่าสร้างบัญชีใหม่เองเพราะ signup ปิดอยู่

ขั้นที่ 4 รู้จักหน้าจอ

ตำแหน่งคืออะไรกดแล้วเกิดอะไร
แถบไอคอนซ้ายสุดเมนูหลักดินสอ = แชทใหม่, แว่น = ค้นหาประวัติ, โฟลเดอร์ = ไฟล์
ตัวอักษรใหญ่ตรงกลางโมเดลที่เลือกอยู่ตอน Nemotron จะเป็นชื่อสั้น ตอน Qwen 35B จะเป็นชื่อเต็มตามภาพด้านบน
กล่อง How can I help you today?ช่องพิมพ์คลิกแล้วพิมพ์คำถาม
ชื่อโมเดลในกล่องล่างขวาตัวเลือกโมเดลคลิกเพื่อเปลี่ยนถ้ามีมากกว่าหนึ่ง
ไอคอนไมค์พูดแทนพิมพ์ต้องอนุญาตไมค์ในเบราว์เซอร์ก่อน
วงกลมส้มมุมล่างซ้ายบัญชีผู้ใช้เปิดเมนูตั้งค่าส่วนตัว

ขั้นที่ 5 เลือกโมเดล

  1. ดูชื่อโมเดลบนหน้า

    ถ้าตรงกลางขึ้นชื่อที่ต้องการ แสดงว่าเลือกอยู่แล้ว

  2. คลิกชื่อโมเดลในกล่องพิมพ์ด้านขวาล่าง
  3. รอรายการเด้งขึ้น

    ต้องเห็นช่อง Search a model

  4. คลิกโมเดลที่ต้องการจนมีเครื่องหมายถูก
  5. คลิกที่ว่างนอกกล่อง หรือกด Escape
ถ้าเปิดรายการแล้วไม่มี Nemotron หรือ Qwen ให้ไปหมวดโมเดล แล้วรัน llm-status

ขั้นที่ 6 ส่งข้อความแรก

  1. คลิกในกล่อง How can I help you today?

    เคอร์เซอร์ต้องกระพริบในกล่อง

  2. พิมพ์ข้อความสั้น ๆ เป็นการทดสอบ

    ตัวอย่างที่ใช้จริง: ตอบคำเดียวว่า pong

  3. ดูปุ่มลูกศรขึ้นสีดำทางขวาของกล่อง
  1. กด Enter หรือคลิกปุ่มลูกศรขึ้น
  2. รอคำตอบ

    Nemotron อาจโชว์คำว่า Thought ชั่วคราว อย่าปิดหน้าต่าง

  3. อ่านคำตอบใต้ชื่อโมเดล

    ถ้าทดสอบด้วยประโยคด้านบน คำตอบควรเป็น pong

ขั้นที่ 7 แชทต่อและเปิดแชทใหม่

  1. พิมพ์ต่อในช่อง Send a Message ด้านล่าง
  2. กด Enter เพื่อส่งข้อความถัดไป
  3. อยากเริ่มเรื่องใหม่ ให้คลิกไอคอนดินสอซ้ายสุด

    นี่คือ New Chat ห้องเก่ายังอยู่ในประวัติ

  4. เปิดประวัติด้วยไอคอนแว่นขยายทางซ้าย
  5. ไอคอนใต้คำตอบ

    ดินสอ = แก้, ก๊อปปี้ = คัดลอก, ลำโพง = อ่าน, นิ้ว = ให้คะแนน, ลูกศรวง = สร้างใหม่

ขั้นที่ 8 ตั้งค่าการสุ่มคำตอบ

  1. อยู่หน้าแชทที่มีโมเดลถูกเลือกแล้ว
  2. เปิดแผง Controls / Chat Controls มุมบนขวา
  3. ตั้ง Temperature เป็น 1.0
  4. ตั้ง Top P เป็น 0.95
  5. ถ้าโมเดลคิดยาวเกิน ให้ปิด thinking

    หรือบอกในข้อความว่าไม่ต้องคิดยาว

ค่าที่ NVIDIA แนะนำสำหรับ Nemotron คือ Temperature 1.0 และ Top P 0.95

ขั้นที่ 9 ตั้งค่าแอดมิน

  1. คลิกวงกลมส้มมุมล่างซ้าย
  2. เลือก Admin Settings หรือ Settings
  3. ตรวจว่าเวอร์ชันขึ้น v0.11.0

อย่าปิดสวิตช์มั่ว ถ้าไม่รู้ว่าทำอะไร ให้กด Back แล้วออก

ขั้นที่ 10 ตรวจการต่อ API

หน้าเว็บไม่ได้รันโมเดลเอง มันถามเซิร์ฟเวอร์ vLLM ชื่อ vllm พอร์ต 8000

  1. ใน Admin Settings คลิก Connections ทางซ้าย หมวด AI
  2. ดูว่า OpenAI API เปิดอยู่

    สวิตช์ต้องสีเข้ม และที่อยู่ต้องเป็น http://vllm:8000/v1

  3. ไม่ต้องไปยุ่งกับ Ollama API

    เครื่องนี้ไม่ได้ใช้ Ollama

  4. คลิก Models ทางซ้ายเพื่อดูว่าเว็บมองเห็นโมเดลหรือไม่
กลับเริ่มต้น ถัดไปเปิด-ปิดโมเดล
