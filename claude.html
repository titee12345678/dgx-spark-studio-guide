A · ล็อกอินแล้วใช้ Claude Pro

สถานะบนเครื่องนี้ตอนเขียน: claude auth status = ไม่ได้ล็อกอิน ต้องทำขั้นล็อกอินก่อน

  1. เปิดเทอร์มินัลบน DGX
  2. ล็อกอินด้วยแผน Claude
    claude-use login

    คำสั่งนี้เรียก claude auth login --claudeai จะเปิดเบราว์เซอร์ให้เข้าบัญชีที่จ่าย Pro / Max / Team

  3. ถ้าจะจ่ายรายคำขอจาก Anthropic Console แทน
    claude-use login --console

    คนละบิลกับ Claude Pro ใช้เมื่อมี API key จาก console

  4. ตรวจว่าเข้าแล้ว
    claude-use status

    บรรทัด Cloud ต้องเป็น logged in: yes

  5. เข้าโฟลเดอร์โปรเจกต์ แล้วเปิดแบบคลาวด์
    cd /path/to/your/project
claude-use pro

    ต้องเห็นบรรทัด Claude Code → Anthropic cloud ถ้าขึ้นว่าชี้ไป :8000 แปลว่าเผลอเปิด local

  6. ในเซสชัน ดูโควตา
    /usage

    หน้านี้บอกว่าแผนเหลือเท่าไร และรีเซ็ตเมื่อไหร่

อย่าใส่ ANTHROPIC_BASE_URL ใน ~/.claude/settings.json ค่านี้จะลากทั้ง claude และ Pro เข้าเครื่อง แล้วล็อกอินไม่มีผล
อยากประหยัดโควตา Pro ให้พิมพ์ /model haiku ในเซสชัน หรือเปิดด้วย claude-use pro --model haiku

B · โควตา Pro หมด แล้วไป local

Claude Code รุ่นบนเครื่องนี้ ไม่มีสวิตช์อัตโนมัติ จากแผนที่หมดไปหา vLLM ในเซสชันเดียวกัน --fallback-model ใช้ได้แค่โหมด -p/--print และสลับได้แค่โมเดลของ Anthropic ตอนเซิร์ฟเวอร์แน่น ไม่ใช่ตอนแผนหมด

  1. ยืนยันว่าแผนหมดจริง

    ในเซสชัน Pro พิมพ์ /usage หรืออ่านข้อความว่า hit your limit / usage limit

  2. ออกจากเซสชัน

    พิมพ์ /exit หรือกด Ctrl + C จนกลับเชลล์

  3. เปิดโมเดลในเครื่องถ้ายังไม่เปิด
    claude-use local qwen35

    รอ Ready ถ้ายังโหลด ใช้เวลา 2–6 นาที

  4. ถ้าโมเดลเปิดอยู่แล้ว
    claude-use local
  5. เมื่อแผน Pro รีเซ็ต

    ออกจาก local แล้วพิมพ์ claude-use pro เซสชันเก่าคนละเส้น อย่าคาดว่าประวัติคลาวด์จะตามมา local

ทางเลือกอื่นตอนแผนใกล้หมด: เปิด Extra usage ที่ claude.ai/settings/usage หรือรอรีเซ็ต แล้วยังใช้ Pro ต่อได้โดยไม่ต้องลง local

C · ใช้โมเดลในเครื่อง

vLLM บนพอร์ต 8000 พูด Anthropic Messages API ได้ Claude Code จึงใช้ก้อนเดียวกับแชทได้ เปิดโมเดลได้ทีละตัว

  1. เลือกโมเดล
    งานคำสั่งชื่อที่ Claude ใช้
    เขียนโค้ด แนะนำclaude-use local qwen35Qwen3.6-35B
    แชทโค้ดทั่วไปclaude-use local qwen27Qwen3.6-27B
    งานยาว บริบท 500kclaude-use local nemotronNemotron-3.5-Lightning
  2. ตรวจชื่อสั้น
    claude-use status

    ต้องเห็น (ok for Claude Code) ชื่อที่มี / ใช้กับ Hermes ได้ แต่ Claude Code ใช้ไม่ได้

  3. เข้าโฟลเดอร์งาน แล้วเปิด
    cd /path/to/your/project
claude-use local

    ต้องเห็น Claude Code → http://127.0.0.1:8000 model=...

สลับโมเดล local และกลับไป Pro

  1. ออกจากเซสชันที่เปิดอยู่

    พิมพ์ /exit

  2. สลับโมเดลในเครื่อง
    claude-use local nemotron
  3. กลับไป Pro
    claude-use pro

    ถ้าขึ้นว่ายังไม่ล็อกอิน ให้รัน claude-use login ก่อน

อย่าเปิด claude-use pro ค้าง แล้วไปรัน start-qwen35 ในอีกแท็บ คนละเส้นทาง โมเดล local ไม่ได้ถูกใช้โดยเซสชัน Pro แต่จะกิน RAM ทับเครื่อง

สิ่งที่ทำไม่ได้ และวิธีเพิ่มโมเดล

สิ่งที่คนมักเข้าใจผิด

  • --fallback-model haiku ไม่ได้พาไป Qwen ใช้ได้เฉพาะ claude -p --fallback-model sonnet,haiku เมื่อโมเดลหลักของ Anthropic แน่น
  • พิมพ์แค่ claude หลังตั้ง ANTHROPIC_BASE_URL ทั้งเครื่อง จะไม่กลับไป Pro
  • Hermes ที่ :18789 คนละโปรแกรม อย่าสับสนกับ Claude Code

เพิ่มโมเดล local ในอนาคต

  1. ใส่โปรไฟล์ใน compose พร้อมชื่อสั้นไม่มี /
    - --served-model-name
- MyNewModel
- --enable-auto-tool-choice
  2. สร้าง start-mynew ที่เรียก llm start mynew
  3. เปิดด้วย claude-use local mynew

    wrapper อ่าน /v1/models เอง ไม่ต้องแก้ไฟล์ Claude
