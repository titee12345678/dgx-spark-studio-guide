Claude Code ในเทอร์มินัล

อ่านโค้ดในโฟลเดอร์ที่เปิดอยู่ แก้ไฟล์ รันคำสั่ง ใช้โมเดลก้อนเดียวกับแชทผ่านพอร์ต 8000

คำสั่ง claude เปล่า ๆ

ยังคุยกับ Anthropic ตามปกติ ไม่ถูกชี้เข้าเครื่องนี้ เพื่อไม่ให้ทุกเซสชันเผลอใช้โมเดล local

จำแบบนี้: อยากคุยในเบราว์เซอร์ใช้ Open WebUI อยากให้เอเจนต์ในกรงทำงานใช้ Hermes อยากให้ตัวช่วยเขียนโค้ดในเทอร์มินัลใช้ claude-local

สถานะบนเครื่องนี้

ตรวจจากไฟล์และคำสั่งจริง วันที่ 18 สิงหาคม 2026

  • Claude Code อยู่ที่ ~/.local/bin/claude เวอร์ชัน 2.1.233
  • vLLM ภาพ vllm/vllm-openai:latest คือ 0.27.1 มี Anthropic Messages API ที่ /v1/messages รองรับ role ที่ Claude Code รุ่นใหม่ส่งมาแล้ว (แก้ใน vLLM 0.23.0)
  • คำสั่งใหม่: claude-local ไฟล์จริง /home/dgxspark/ai/open-webui/claude-local ลิงก์ที่ ~/.local/bin/claude-local
  • พิมพ์ start-claude ได้เหมือนกัน เป็นลิงก์ไปไฟล์เดียวกัน
  • โมเดลที่สลับได้ตอนนี้: qwen35 qwen27 nemotron เปิดได้ทีละตัวบนพอร์ต 8000
  • ชื่อที่ Claude Code ใช้ต้องไม่มีเครื่องหมาย / ดังนั้น wrapper จะเลือกชื่อสั้น เช่น Qwen3.6-35B ไม่ใช้ nvidia/Qwen3.6-35B-A3B-NVFP4

ทำไมต้องใช้ wrapper

Claude Code พูดภาษา Anthropic Messages API ไม่ใช่ภาษา OpenAI ที่ Open WebUI ใช้ vLLM บนเครื่องนี้พูดได้ทั้งสองภาษาที่พอร์ตเดียวกัน

  1. โปรแกรมยิงไปที่ ANTHROPIC_BASE_URL

    ค่าเริ่มต้นคือเซิร์ฟเวอร์ของ Anthropic ถ้าไม่เปลี่ยน claude จะออกเน็ต

  2. wrapper ตั้ง URL เป็น http://127.0.0.1:8000

    คำขอไปที่ vLLM ในเครื่อง คีย์ใส่ dummy ได้เพราะ vLLM ไม่ตรวจจริง

  3. Claude Code ยังเรียกโมเดลชื่อ opus / sonnet / haiku ข้างใน

    ต้อง remap ทั้งสามชื่อไปที่ชื่อที่ API ประกาศจริง ไม่เช่นนั้นจะได้ 404

  4. ชื่อถูกอ่านจาก GET /v1/models ทุกครั้งที่เปิด

    สลับโมเดลแล้วไม่ต้องไปแก้ ~/.claude/settings.json

อย่าใส่ ANTHROPIC_BASE_URL ลงใน ~/.claude/settings.json ของทั้งเครื่อง ค่านี้จะทำให้คำสั่ง claude ธรรมดาชี้เข้า local ทั้งหมด แล้วเลิกคุยกับ Anthropic ได้โดยไม่ตั้งใจ

ขั้นที่ 1 เปิดโมเดล

Claude Code ไม่ได้โหลดโมเดลเอง มันยิงไปพอร์ต 8000 เหมือน Open WebUI และ Hermes เปิดได้ทีละตัว

  1. เปิดเทอร์มินัลบนเครื่อง DGX
  2. เลือกโมเดลที่อยากให้เขียนโค้ด
    งานคำสั่งเปิดชื่อที่ Claude Code จะใช้
    เขียนโค้ด / เรียกเครื่องมือ แนะนำตัวนี้start-qwen35Qwen3.6-35B
    แชทโค้ดทั่วไป กิน RAM สูงกว่าstart-qwen27Qwen3.6-27B
    งานยาว มี speculative decodingstart-nemotronNemotron-3.5-Lightning

    ทั้งสามสูตรเปิด --enable-auto-tool-choice อยู่แล้ว Claude Code ต้องมี tool calling

  3. รอจนขึ้น Ready.

    ใช้เวลาประมาณ 2–6 นาที อย่าปิดแท็บ อย่ากด Ctrl+C

  4. ตรวจชื่อที่ API ประกาศ
    llm-status
claude-local --status

    ต้องเห็นบรรทัด (ok for Claude Code) อย่างน้อยหนึ่งชื่อ และบรรทัด Will map opus/sonnet/haiku

ข้ามขั้นนี้ได้ถ้าพิมพ์ claude-local qwen35 อันเดียว มันจะเรียก start-qwen35 ให้ก่อนแล้วค่อยเปิด Claude Code

ขั้นที่ 2 เปิด claude-local

  1. เข้าโฟลเดอร์โปรเจกต์ที่จะให้มันแตะไฟล์
    cd /path/to/your/project

    Claude Code ทำงานกับโฟลเดอร์ปัจจุบัน ไม่ใช่ทั้งเครื่องโดยอัตโนมัติ

  2. พิมพ์คำสั่งนี้ แล้วกด Enter
    claude-local

    ถ้ายังไม่ได้เปิดโมเดล ให้ระบุชื่อเลย

    claude-local qwen35
  3. อ่านบรรทัดแรกที่พิมพ์ออกมา

    ต้องคล้าย Claude Code → http://127.0.0.1:8000 model=Qwen3.6-35B ถ้าไม่ขึ้นบรรทัดนี้ แปลว่าเปิด claude เปล่า ๆ อยู่

  4. รอจนเข้าเซสชันเทอร์มินัลของ Claude Code

    พิมพ์งานได้ตามปกติ เช่น อ่านไฟล์ แก้บั๊ก เขียนฟังก์ชัน

ขั้นที่ 3 ตรวจว่าใช้โมเดลในเครื่อง

  1. ดูสถานะก่อนเข้าเซสชัน
    claude-local --status
  2. ดูรายการโมเดลดิบจาก API
    curl -s http://127.0.0.1:8000/v1/models

    ต้องเป็น JSON มี id อย่างน้อยหนึ่งอันที่ไม่มี /

  3. ทดสอบ Anthropic Messages API โดยไม่เปิดตัวช่วยเขียนโค้ด
    curl -s http://127.0.0.1:8000/v1/messages \
  -H 'content-type: application/json' \
  -H 'x-api-key: dummy' \
  -H 'anthropic-version: 2023-06-01' \
  -d '{"model":"Qwen3.6-35B","max_tokens":32,"messages":[{"role":"user","content":"Reply with exactly: pong"}]}'

    ถ้าโมเดลเป็นตัวอื่น ให้เปลี่ยนช่อง model เป็นชื่อที่ claude-local --status บอกว่าจะ map

  4. ในเซสชัน Claude Code ส่งข้อความสั้น ๆ

    ถ้าตอบได้ แปลว่า remap ชื่อ opus/sonnet/haiku ทำงาน ถ้าขึ้น model not found ให้กลับไปขั้นที่ 1

สลับโมเดลตอนนี้

พอร์ต 8000 มีที่เดียว เปิดโมเดลใหญ่ได้ทีละก้อน สลับแล้วเซสชัน Claude Code เก่าจะขาดการเชื่อมต่อ

  1. ออกจาก Claude Code

    พิมพ์ /exit หรือกด Ctrl + C จนกลับมาที่เชลล์

  2. สั่งเปิดตัวใหม่ด้วยคำสั่งเดียว
    claude-local nemotron

    หรือ claude-local qwen27 หรือ claude-local qwen35

  3. รอ Ready แล้วอ่านบรรทัด model=...

    ชื่อต้องเปลี่ยนตามตัวที่เพิ่งเปิด เช่น model=Nemotron-3.5-Lightning

ถ้าอยากเปิดโมเดลแยก แล้วค่อยเข้า Claude Code คนละแท็บ

start-nemotron
claude-local --status
claude-local
อย่าเปิด claude-local ค้างไว้แล้วไปรัน start-qwen35 ในอีกแท็บ คอนเทนเนอร์เก่าจะถูกปิด พอร์ต 8000 ว่างชั่วคราว เซสชันที่เปิดอยู่จะพัง

เพิ่มโมเดลใหม่ในอนาคต

ไม่ต้องแก้ Claude Code และไม่ต้องแก้ claude-local ให้ตามสามขั้นนี้ แล้วชื่อจะถูกอ่านจาก API เอง

  1. ใส่โปรไฟล์ใหม่ใน docker-compose

    ไฟล์ /home/dgxspark/ai/open-webui/docker-compose.yml ดูบล็อก qwen35: แล้วคัดแบบมา เปลี่ยนชื่อบริการ ชื่อคอนเทนเนอร์ และพาธโมเดล

    - --served-model-name
- MyNewModel

    ชื่อนี้ห้ามมี / ห้ามเป็นแค่ org/name จาก Hugging Face Claude Code รับไม่ได้

  2. เปิด tool calling

    ต้องมีสองธงนี้ ไม่งั้น Claude Code เรียกเครื่องมือในเทอร์มินัลไม่ได้

    - --enable-auto-tool-choice
- --tool-call-parser
- qwen3_coder

    ค่า parser ต้องตรงตระกูลโมเดล ดูเอกสาร vLLM ไม่ใช่ก็อปของ Qwen ทุกครั้ง

  3. เพิ่มคำสั่ง start ของสตูดิโอ

    ใน /home/dgxspark/ai/open-webui/llm ใส่ชื่อโปรไฟล์ลง MODELS แล้วสร้างลิงก์

    cat > ~/.local/bin/start-mynew <<'EOF'
#!/usr/bin/env bash
exec /home/dgxspark/ai/open-webui/llm start mynew
EOF
chmod +x ~/.local/bin/start-mynew

    คำว่า mynew ต้องตรงกับชื่อโปรไฟล์ใน compose

  4. เปิดด้วย wrapper
    claude-local mynew

    wrapper เดินหา start-* ที่เรียก llm start เอง ไม่ต้องไปเพิ่มรายชื่อในสคริปต์ Claude

  5. ตรวจว่าชื่อสั้นถูกเลือก
    claude-local --status

    ต้องเห็น MyNewModel (ok for Claude Code) ถ้ามีแต่ชื่อที่มี / wrapper จะปฏิเสธและบอกให้ใส่ alias

อยากบังคับชื่อเองโดยไม่ให้เลือกอัตโนมัติ ใส่ CLAUDE_LOCAL_MODEL=MyNewModel ข้างหน้าคำสั่ง ชื่อนี้ต้องอยู่ใน /v1/models และต้องไม่มี /

ตัวแปรที่ wrapper ตั้งให้

ไม่ต้องพิมพ์เอง เปิดดูเพื่อรู้ว่าถ้าเซสชันชี้ผิดที่ ผิดตรงไหน

ตัวแปรค่าบนเครื่องนี้หน้าที่
ANTHROPIC_BASE_URLhttp://127.0.0.1:8000ชี้ Claude Code ไป vLLM
ANTHROPIC_API_KEYdummyvLLM ไม่ตรวจคีย์
ANTHROPIC_AUTH_TOKENdummyClaude Code บังคับให้มี
ANTHROPIC_DEFAULT_OPUS_MODELชื่อสั้นจาก APIงานระดับ opus ไปโมเดลในเครื่อง
ANTHROPIC_DEFAULT_SONNET_MODELชื่อสั้นจาก APIงานระดับ sonnet ไปโมเดลเดียวกัน
ANTHROPIC_DEFAULT_HAIKU_MODELชื่อสั้นจาก APIงานเบาระดับ haiku ไปโมเดลเดียวกัน
CLAUDE_CODE_ATTRIBUTION_HEADER0กันพรอมต์เปลี่ยนทุกคำขอ ช่วย prefix cache

บนเครื่องนี้เปิดโมเดลได้ทีละตัว เลย map ทั้ง opus sonnet haiku ไปก้อนเดียวกัน ไม่ได้แยกโมเดลเล็กให้ haiku

กลับไปใช้ Claude ของ Anthropic

  1. ออกจากเซสชันที่เปิดด้วย claude-local
  2. พิมพ์คำสั่งเดิมของ Anthropic
    claude

    คำสั่งนี้ไม่ได้อ่าน wrapper จึงไปคลาวด์ตามที่ล็อกอินไว้

  3. ตรวจว่า settings ไม่ได้ล็อก URL
    cat ~/.claude/settings.json

    ต้องไม่มีคีย์ ANTHROPIC_BASE_URL ในบล็อก env

โมเดลในเครื่องยังเปิดอยู่ได้ตอนใช้ claude คลาวด์ มันคนละเส้นทาง ถ้าไม่ได้ใช้ local แล้ว ให้รัน stop-model เพื่อคืน RAM

ปัญหาที่เจอบนเครื่องนี้

ขึ้นว่า No model is listening

  1. รัน llm-status
  2. ถ้า Model: stopped ให้รัน claude-local qwen35 หรือเปิดโมเดลก่อน
  3. รอ Ready อย่าเพิ่งเปิด Claude Code ซ้ำตอนยังโหลด

Model not found / 404

  1. รัน claude-local --status ดูว่าชื่อที่ map มีในรายการหรือไม่
  2. ถ้าเห็นแต่ชื่อที่มี / ให้แก้ compose ใส่ชื่อสั้น แล้วสตาร์ทใหม่
  3. อย่าพิมพ์ claude --model nvidia/Qwen3.6-35B-A3B-NVFP4 เครื่องหมายทับทำให้ Claude Code หาไม่เจอ

Connection refused

พอร์ต 8000 ว่าง โมเดลยังไม่ขึ้น หรือถูก stop-model ไปแล้ว

Tool calls ไม่ทำงาน

สูตรสตูดิโอตอนนี้เปิด auto tool choice แล้ว ถ้าเพิ่มโมเดลใหม่แล้วลืมธงนี้ Claude Code จะคุยได้แต่เรียกเครื่องมือไม่เป็น ดูขั้น เพิ่มโมเดลใหม่

เคยพังกับ Claude Code 2.1.154

รุ่นนั้นส่ง role แปลกใน messages แล้ว vLLM เก่าตอบ 400 เครื่องนี้ใช้ vLLM 0.27.1 และ Claude Code 2.1.233 ชุดนี้ผ่านแพตช์แล้ว ไม่ต้องดาวน์เกรด Claude Code

เผลอใช้ qwen35-start

คนละคำสั่งกับสตูดิโอ อ่านที่ สองคำสั่งคนละตัว ใช้ start-qwen35 หรือ claude-local qwen35 อันเดียว
