  • คอนเทนเนอร์ comfyui-dgx เปิดอยู่ พอร์ต 8188 ตอบ HTTP 200

ขั้นที่ 1 เปิดโปรแกรม

ทำบนเครื่อง DGX ผ่านเทอร์มินัล ไม่ใช่ในกรง Hermes

  1. เปิดเทอร์มินัล

    กด Ctrl + Alt + T

  2. ตรวจว่าเปิดอยู่หรือยัง
    docker ps --filter name=comfyui-dgx

    ถ้า STATUS เป็น Up ... ไปขั้นที่ 2 ได้เลย

  3. ถ้ายังไม่เปิด ใช้สคริปต์ที่เตรียมไว้
    ~/ai/comfyui/scripts/start.sh

    คำสั่งนี้ปลุกคอนเทนเนอร์เดิม ถ้ายังไม่มีจะสร้างใหม่โดยไม่แตะโมเดลแชท

  4. ถ้าอยากดูว่าพร้อมหรือยัง
    docker logs --tail 30 comfyui-dgx

    ต้องเห็นข้อความประมาณ To see the GUI go to: http://0.0.0.0:8188

ถ้าจะรันสร้างภาพใหญ่หรือวิดีโอ แนะนำให้ stop-model ก่อน เพราะเครื่องนี้ RAM รวมกับ GPU ก้อนเดียว

ขั้นที่ 2 เข้าเว็บ

  1. เปิดแท็บเบราว์เซอร์ใหม่
  2. พิมพ์ที่อยู่แล้วกด Enter

    บนเครื่องนี้: http://127.0.0.1:8188

    จากเครื่องอื่นในบ้าน: http://192.168.178.98:8188

  3. ตรวจว่าหน้าขึ้นจริง

    ต้องเห็นผืนผ้าใบสีเข้ม แถบซ้ายมี Assets / Nodes / Models / Workflows / Templates และมุมบนมีปุ่มฟ้า Run

ขั้นที่ 5 วางโมเดล

ComfyUI ไม่ได้ดาวน์โหลดโมเดลใหญ่ตอนติดตั้ง ตอนนี้ทุกโฟลเดอร์ใน ~/ai/comfyui/models ยังว่าง

ชนิดไฟล์วางที่ใช้กับงาน
Checkpoint แบบเก่า เช่น SD 1.5models/checkpointsภาพทดสอบเล็ก
Diffusion ใหม่ เช่น Z-Image, FLUX, Wanmodels/diffusion_modelsกราฟเริ่มต้นและวิดีโอ
Text encoder / CLIP / T5 / Qwenmodels/text_encoders หรือ clipอ่านพรอมต์
VAEmodels/vaeถอด latent เป็นรูป
อัปสเกลmodels/upscale_modelsขยายภาพทีหลัง
น้ำหนัก RIFEตามที่โหนด Frame Interpolation บอกเพิ่มเฟรมวิดีโอ
  1. เปิดโฟลเดอร์โมเดล
    xdg-open ~/ai/comfyui/models
  2. คัดลอกไฟล์ .safetensors ลงโฟลเดอร์ที่ถูกชนิด
  3. กลับไปหน้าเว็บ รีเฟรชรายการในโหนด หรือรีสตาร์ท
    docker restart comfyui-dgx
  4. กรอบแดงต้องหาย ถ้ายังแดง ให้คลิกช่องชื่อไฟล์ในโหนดแล้วเลือกไฟล์ที่เพิ่งวาง
อย่าพิมพ์ Hugging Face token ลงคำสั่งที่เทอร์มินัลจะบันทึกประวัติ ถ้าโมเดลเป็นแบบ gated ให้รัน docker exec -it comfyui-dgx hf auth login แล้ววาง token ในช่องที่ถาม

ขั้นที่ 6 งานแรกจากกราฟที่มีอยู่

เครื่องนี้เปิดมาพร้อมกราฟ Z-Image-Turbo ไม่ต้องสร้างกราฟใหม่สำหรับงานแรก

  1. ดูโหนดกรอบแดง

    Load Diffusion Model ต้องการ z_image_turbo_bf16.safetensors ประมาณ 11.46 GB

    Load CLIP ต้องการ qwen_3_4b.safetensors ประมาณ 7.49 GB

  2. เปิดรายการที่ขาด

    มุมขวาบนมีป้าย errors ให้กด View details แผงขวาจะขึ้น Missing Models

  1. ดาวน์โหลดเมื่อเครื่องว่าง

    กด Download ทีละไฟล์ อย่ากด Download all ตอนโมเดลแชทยังกิน RAM

  2. รอจนกรอบแดงหาย

    ไฟล์ตกที่ diffusion_models และ text_encoders แล้วรีเฟรชโหนด

  3. แก้ข้อความในโหนด CLIP ช่องบวก

    คลิกโหนด CLIP Text Encode อันบน แล้วพิมพ์ใหม่ที่แผงขวาช่อง text ช่องล่างเป็นพรอมต์ลบ

  1. ตั้งค่างานทดสอบให้เล็ก

    โหนด EmptySD3LatentImage ตอนนี้ 1024×1024 งานแรกให้ลดเป็น 768×768

    KSampler ของกราฟนี้ใช้ steps 8, cfg 1.0, sampler res_multistep เหมาะกับ Z-Image-Turbo อยู่แล้ว อย่าเพิ่ม steps มากในรอบแรก

  2. กด Run

    ปุ่มฟ้ามุมบน หรือ Ctrl + Enter ตัวเลข 0 active จะขยับขึ้นขณะทำงาน

  3. ดูผล

    รูปโชว์ที่โหนด Save Image และไปอยู่ที่ ~/ai/comfyui/output ในเว็บดูได้ที่ Assets

ขั้นที่ 7 สร้างภาพจากข้อความ

ใช้เมื่ออยากเริ่มจากเทมเพลต ไม่ใช้กราฟที่เปิดมา ถ้ายังไม่มีโมเดล ทำได้ถึงแค่เปิดเทมเพลต แล้วโหนดโหลดจะแดง

  1. คลิก Templates ทางซ้าย

    จะได้หน้าต่าง All Templates

  1. คลิก Image ใต้ Generation Type
  1. เปิดการ์ดสร้างภาพ

    คลิก Z-Image-Turbo: Text to Image หรือเทมเพลตภาพอื่นที่ไฟล์มีครบ

  2. เลือกไฟล์ในโหนดโหลด

    SD 1.5 ใช้ Load Checkpoint ใน checkpoints ส่วน Z-Image / FLUX / Wan ใช้ Load Diffusion Model ใน diffusion_models

  3. เขียนพรอมต์ช่องบวก
    a ceramic coffee cup on a teak table, morning window light, photorealistic, 35mm

    ช่องลบใส่สิ่งที่ไม่ต้องการ เช่น blurry, watermark, extra fingers

  4. ตั้งค่างานทดสอบให้เล็ก
    • ความกว้าง/สูง: 512 หรือ 768 ก่อน
    • Steps: ตามโมเดล เช่น Z-Image-Turbo ประมาณ 8, SD 1.5 ประมาณ 20
    • Batch size: 1
  5. กด Run แล้วรอโหนด Save Image โชว์รูป

ขั้นที่ 8 แก้ภาพเดิม

ใช้เมื่อมีรูปต้นทางแล้วอยากเปลี่ยนบางอย่าง ไม่ใช่สร้างใหม่ทั้งใบ

  1. วางรูปลงเครื่อง

    คัดลอก .png หรือ .jpg ไปที่ ~/ai/comfyui/input

    xdg-open ~/ai/comfyui/input
  2. เปิดเทมเพลตแก้ภาพ

    Templates → Image → Qwen Image Edit 2511 เมื่อมีไฟล์ของกราฟนั้น

  3. ในโหนด Load Image เลือกไฟล์ที่เพิ่งวาง
  4. เขียนสิ่งที่จะเปลี่ยน ให้เฉพาะเจาะจง

    ตัวอย่าง: เปลี่ยนพื้นหลังเป็นห้องครัว แต่คงถ้วยกาแฟเดิม

  5. ตั้งความแรงของการแก้ให้กลาง ๆ

    ค่า denoise ยิ่งสูง ยิ่งทิ้งต้นฉบับมาก รอบแรกอย่าขยับสุด

  6. รันครั้งละหนึ่งรูป แล้วดูใน output
อย่าเพิ่มความละเอียดพร้อมกับแก้ภาพในรอบแรก ให้แก้ให้ถูกก่อน แล้วค่อยไปขั้นอัปสเกล

ขั้นที่ 9 สร้างวิดีโอจากข้อความ

วิดีโอคนละกราฟกับภาพนิ่ง ใช้เวลานานกว่า และกินหน่วยความจำมากกว่ามาก

เริ่มสั้นเสมอ: 3–5 วินาที ความละเอียดไม่เกิน 720p จำนวนชุด 1 งาน ห้ามเริ่มด้วยคลิปยาวหรือ 1080p
  1. อย่าเปิดเทมเพลตวิดีโอก่อนมีโมเดลวิดีโอ

    ตัวที่เหมาะเริ่มต้นคือ Wan2.2 TI2V-5B ทำได้ทั้งข้อความเป็นวิดีโอและภาพเป็นวิดีโอ ดูขนาดในตารางโมเดลด้านล่าง

  2. คลิก Templates แล้วเลือก Video
  1. เปิดการ์ด Text to Video ที่ตรงกับโมเดลที่มี

    ใช้ไฟล์ UI เท่านั้น อย่าเปิดไฟล์นามสกุล .api.json

  2. เขียนพรอมต์แบบมีกล้องและการเคลื่อนไหว
    slow drone shot over a misty teak forest at sunrise, cinematic, gentle camera push-in

    ถ้าระบุแค่วัตถุโดยไม่บอกกล้อง คลิปจะนิ่งเหมือนสไลด์

  3. ตั้งเฟรมให้สั้น

    เป้าหมายแรกประมาณ 49–81 เฟรม ที่ 16–24 fps จะได้คลิปราว 3–5 วินาที

  4. ปิดโมเดลแชทก่อนกด Run
    stop-model
  5. กด Run แล้วรอ นานกว่าภาพมาก

    ผลมักอยู่ที่ ~/ai/comfyui/output บางกราฟได้ .webp ก่อน แปลงเป็น mp4 ได้ด้วย

    docker exec comfyui-dgx ffmpeg -y -i /opt/ComfyUI/output/ชื่อไฟล์.webp /opt/ComfyUI/output/ชื่อไฟล์.mp4
LTX-2.3 แบบมีเสียงยังไม่พร้อมใน image นี้ เพราะ torchaudio ถูก stub ไว้บน ARM64 อย่าเริ่มจาก LTX ถ้าต้องการเสียงในคลิป

ขั้นที่ 10 ทำภาพนิ่งให้เป็นวิดีโอ

ใช้เมื่อมีรูปที่ชอบแล้วอยากให้ขยับ ไม่ใช่สร้างคลิปจากข้อความล้วน

  1. วางรูปนิ่งใน input

    ใช้รูปจากขั้นสร้างภาพ หรือรูปถ่ายของคุณเอง

  2. เปิด Templates → Video → Image to Video

    เลือกกราฟที่ตรงกับโมเดลที่มี เช่น Wan เมื่อไฟล์ครบ

  3. ในโหนด Load Image เลือกไฟล์นั้น
  4. อธิบายการเคลื่อนไหว ไม่ใช่แค่วัตถุ

    เขียนว่ากล้องทำอะไรและวัตถุขยับอย่างไร เช่น กล้องค่อย ๆ เข้าใกล้ ไอน้ำลอยขึ้น ใบไม้สั่นเล็กน้อย

  5. ตั้งเฟรมสั้นเหมือนขั้นที่ 9 แล้วกด Run
รูปต้นทางคมและองค์ประกอบเรียบจะขยับสวยกว่าภาพวุ่นวาย ถ้าผลเพี้ยน ให้ลดความยาวและลดความละเอียดก่อนเปลี่ยนโมเดล

ขั้นที่ 11 อัปสเกลภาพและเพิ่มเฟรมวิดีโอ

ทำทีหลังเมื่อมีไฟล์ผลแล้ว อย่าขยายพร้อมกับสร้างครั้งแรก

ขยายภาพ

  1. วางโมเดล เช่น RealESRGAN x4plus ใน ~/ai/comfyui/models/upscale_models
  2. ดับเบิลคลิกผืนผ้าใบ เพิ่มโหนด Load Image, Upscale Model Loader, Image Upscale With Model, Save Image
  3. ลากรูปเข้าโหนดอัปสเกล แล้วต่อไป Save Image
  4. เริ่มจากภาพไม่ใหญ่เกินไป เพราะขยาย 4 เท่ากินหน่วยความจำเร็ว

เพิ่มเฟรมด้วย RIFE

โหนด RIFE VFI ติดตั้งแล้ว แต่ยังต้องมีไฟล์น้ำหนัก RIFE

  1. โหลดวิดีโอด้วยโหนดของ Video Helper Suite
  2. ต่อเข้า RIFE VFI
  3. ตั้งตัวคูณเฟรมเป็น 2 ก่อน อย่ากระโดดไป 4 หรือ 8 ในรอบแรก
  4. เซฟออกด้วย Video Combine เป็น mp4

บันทึกผลและกราฟ

  1. หาไฟล์ที่สร้างได้
    ls -lt ~/ai/comfyui/output | head
xdg-open ~/ai/comfyui/output
  2. ดูในเว็บที่แผง Assets
  1. บันทึกกราฟที่ใช้ได้แล้ว

    กด Ctrl + S หรือเมนู Graph แล้ว Save ตั้งชื่อให้อ่านรู้เรื่อง เช่น 01_text_to_image.json 03_image_to_video.json

    ไฟล์จะโผล่ใน ~/ai/comfyui/workflows

  2. เปิดกราฟเดิมอีกครั้งจากแผง Workflows หรือลากไฟล์ JSON ลงหน้าเว็บ

ตารางโมเดลที่แนะนำ

ยังไม่ต้องโหลดทั้งหมด เลือกทีละชุด ไฟล์ที่ใหญ่กว่า 20 GB ต่อไฟล์ให้หยุดถามก่อน

โมเดลใช้ทำอะไรขนาดโดยประมาณควรเริ่มเมื่อไร
Z-Image-Turbo + Qwen3 4Bกราฟเริ่มต้น Text-to-Image เร็วรวมราว 19 GBงานแรก กด Download ใน Missing Models
SD 1.5 fp16ทดสอบระบบด้วยภาพเล็กประมาณ 2 GBถ้าไม่อยากใช้ Z-Image
Qwen-Image-Edit 2511แก้ภาพด้วยข้อความราว 10–20 GBหลังสร้างภาพได้แล้ว
Wan2.2 TI2V-5Bข้อความเป็นวิดีโอ และภาพเป็นวิดีโอ 720pมัก 8–15 GB รวม VAE/T5หลังภาพนิ่งใช้งานได้
RealESRGAN x4plusอัปสเกลภาพประมาณ 64 MBเมื่อมีรูปแล้วอยากขยาย
RIFE 4.25+เพิ่มเฟรมวิดีโอสิบถึงร้อย MBเมื่อมีคลิปสั้นแล้ว
FLUX.2 / LTX-2.3 มีเสียงคุณภาพสูง หรือวิดีโอมีเสียงมักเกิน 20 GBทีหลัง LTX ยังไม่พร้อมใน image นี้

RAM กับโมเดลแชท

เครื่องนี้หน่วยความจำก้อนเดียว ทั้งแชท ทั้งภาพ ทั้งวิดีโอ

Qwen 35B เปิดอยู่กันไว้ราว 40%
เว็บ Comfy ยังเปิดได้ แต่ห้ามกด Run วิดีโอทับ
  1. จะสร้างภาพใหญ่หรือวิดีโอ ให้รัน stop-model ก่อน
  2. จะคุยแชทต่อหลังสร้างภาพ ให้รัน start-qwen35 หรือ start-nemotron อีกครั้ง
  3. อย่าเปิด Nemotron ค้างแล้วยิงกราฟ Wan พร้อมกัน

ปัญหาที่เจอบนเครื่องนี้

เข้า :8188 ไม่ได้

  1. รัน ~/ai/comfyui/scripts/start.sh
  2. รอ 10 วินาที แล้วรีเฟรช
  3. ดู docker logs --tail 40 comfyui-dgx จนเจอบรรทัด GUI

กด Run แล้วขึ้น errors / กรอบแดง

ยังไม่มีไฟล์โมเดล ไม่ใช่เครื่องพัง

  1. กด View details
  2. อ่านชื่อไฟล์ที่ขาด
  3. ดาวน์โหลดหรือวางไฟล์ลงโฟลเดอร์ที่ถูกชนิด
  4. รีเฟรชโหนด แล้วค่อยกด Run ใหม่

Manager บอกว่า PyTorch is not installed

เป็นข้อความเท็จของ NGC PyTorch บนเครื่องนี้ ถ้า curl -s http://127.0.0.1:8188/system_stats ยังโชว์ NVIDIA GB10 ไม่ต้องติดตั้ง torch จาก PyPI

สิ่งที่ห้ามทำ

  • ห้ามกด Run ตอนโหนดยังกรอบแดง แล้วคิดว่าเครื่องพัง
  • ห้ามเริ่มวิดีโอยาวหรือ 1080p เป็นงานแรก
  • ห้ามรันวิดีโอคู่โมเดลแชทใหญ่
  • ห้ามลบ ~/ai/comfyui/models หรือ output
  • ห้ามใช้ docker system prune เพื่อเคลียร์พื้นที่โดยไม่ดูชื่อ
  • ห้ามใส่ Hugging Face token ลงประวัติเทอร์มินัล
  • ห้ามไปยุ่งคอนเทนเนอร์โมเดลแชทเพื่อเปิด ComfyUI
  • ห้ามติดตั้ง torchaudio ในคอนเทนเนอร์นี้เพื่อบังคับ LTX ให้มีเสียง
