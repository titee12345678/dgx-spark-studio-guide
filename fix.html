เจออาการแล้วทำทีละข้อ

เลือกอาการทางซ้าย แล้วทำตามลำดับ อย่าข้ามข้อ

เปิด :18473 แล้วหมุนไม่ขึ้น

  1. รัน start-webui
  2. รอ 5 วินาที
  3. รีเฟรชหน้า
  4. ถ้ายังไม่ได้ รัน docker ps --filter name=open-webui ต้องเห็น Up (healthy)

ล็อกอินได้แต่ไม่มีโมเดลให้เลือก

  1. รัน llm-status
  2. ถ้า Model: stopped ให้รัน start-nemotron แล้วรอ Ready
  3. รีเฟรชเว็บ
  4. เปิดตัวเลือกโมเดลอีกครั้ง

กดส่งแล้วค้างหรือ error

  1. ดูว่าโมเดลเพิ่งสตาร์ทหรือยัง ถ้ายังไม่ถึง Ready ให้รอ
  2. เปิดแท็บใหม่ไปที่ http://127.0.0.1:8000/v1/models ต้องเป็น JSON มีชื่อโมเดล
  3. ถ้าหน้า 8000 ไม่ขึ้น ดูล็อกในหมวดระบบ

ขึ้นว่า RAM ไม่พอตอนสตาร์ทโมเดล

  1. ปิดแท็บ Chrome / Firefox ที่ไม่ใช้
  2. รัน stop-model แล้วลองใหม่
  3. อย่าเปิดโมเดลสองตัว
  4. ถ้ายังสร้างภาพใน ComfyUI อยู่ ให้รอให้เสร็จหรือปิด ComfyUI ชั่วคราว

เข้า :8188 ไม่ได้

  1. รัน ~/ai/comfyui/scripts/start.sh ไม่ใช่ไปยุ่งคอนเทนเนอร์โมเดลแชท
  2. รอ 10 วินาที
  3. รีเฟรช http://127.0.0.1:8188
  4. ถ้ายังไม่ได้ ดู docker logs --tail 40 comfyui-dgx จนเจอบรรทัด GUI

กด Run ใน ComfyUI แล้วขึ้น errors

กรอบแดงหรือ Missing Models แปลว่ายังไม่มีไฟล์ ไม่ใช่เครื่องพัง

  1. อ่านแผง Errors ด้านขวา แล้วกด View details
  2. ถ้าขาด Z-Image หรือ CLIP ให้ไปหมวด งานแรก
  3. ถ้าจะทำวิดีโอ ต้องมีโมเดลวิดีโอแยก ดู ข้อความเป็นวิดีโอ
  4. อย่าเพิ่งกด Download all ถ้ายังมีโมเดลแชทกิน RAM

แยกอาการก่อน แดชบอร์ดไม่ขึ้น คนละเรื่องกับแดชบอร์ดขึ้นแต่ตอบ 404

แดชบอร์ดไม่ขึ้น

  1. เปิดจากเครื่อง DGX เท่านั้น http://127.0.0.1:18789/
  2. รัน nemoclaw hermes status
  3. ถ้า sandbox หยุด รัน nemoclaw hermes start
  4. ถ้าพอร์ตยังเงียบ รัน nemoclaw hermes recover

แดชบอร์ดขึ้น แต่ส่งข้อความแล้ว 404 / โมเดลไม่มี

นี่ไม่ใช่ Hermes พัง ชื่อที่เอเจนต์ยิงไม่ตรงกับชื่อที่ vLLM ประกาศ

  1. อย่าพิมพ์ qwen35-start ใช้ start-qwen35 อันเดียว
  2. รอ Ready จนเห็น nvidia/Qwen3.6-35B-A3B-NVFP4
  3. ตรวจ curl -s http://127.0.0.1:8000/v1/models ต้องมีชื่อเต็ม
  4. ตรวจ nemoclaw hermes status บรรทัด Inference ต้อง healthy
  5. ส่งข้อความในห้องใหม่ อย่าดูห้องเก่าที่ error ค้าง

Claude Code ไม่ยิงโมเดลในเครื่อง

  1. รัน claude-use status แยกว่าจะใช้ Pro หรือ local
  2. อยากได้คลาวด์: claude-use login แล้ว claude-use pro
  3. โควตาหมด: ออกจากเซสชัน แล้ว claude-use local ไม่มีสวิตช์อัตโนมัติ
  4. local ไม่ขึ้น: claude-use local qwen35 ต้องเห็นชื่อสั้นไม่มี /
  5. อย่าใส่ ANTHROPIC_BASE_URL ใน ~/.claude/settings.json
  6. เรื่องยาวอยู่ที่ หมวด Claude Code
