ขั้นที่ 1 เปิดเทอร์มินัล

คำสั่งเปิด-ปิดโมเดลพิมพ์ในเทอร์มินัลบนเครื่อง DGX ทำทุกข้อตามลำดับ

  1. นั่งที่เครื่อง DGX หรือรีโมตเข้ามา

    ถ้าอยู่หน้าจอเครื่องนี้ ใช้คีย์บอร์ดเมาส์ของเครื่องโดยตรง ถ้าอยู่เครื่องอื่น ให้รีโมตด้วย AnyDesk หรือ SSH มาก่อน

  2. เปิดหน้าต่างเทอร์มินัล

    กด Ctrl + Alt + T พร้อมกันแล้วปล่อย หรือคลิกมุมล่างซ้ายของ GNOME แล้วพิมพ์ Terminal แล้วกด Enter

  3. ดูให้แน่ใจว่าพร้อมพิมพ์

    ต้องเห็นเคอร์เซอร์กระพริบหลังข้อความประมาณ dgxspark@spark:~$ อย่าพิมพ์คำสั่งในช่องค้นหาของเว็บ

ขั้นที่ 2 ตรวจว่าอะไรเปิดอยู่

  1. พิมพ์คำสั่งนี้แล้วกด Enter
    llm-status
  2. อ่านผล
    • Open WebUI: running = หน้าเว็บแชทเปิดแล้ว
    • Model container: ... (running) = มีโมเดลโหลดอยู่ กิน RAM มาก
    • API model: ... = ชื่อโมเดลที่หน้าเว็บจะเลือกได้
    • Model: stopped = ยังคุยไม่ได้ ไปหมวดโมเดล
  3. ดูคอนเทนเนอร์ทั้งหมดถ้าต้องการรายละเอียด
    docker ps --format 'table {{.Names}}\t{{.Status}}\t{{.Ports}}'
