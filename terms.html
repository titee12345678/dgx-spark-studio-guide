วิธีใช้หน้านี้

ไม่ต้องท่องทั้งหน้า อ่านหมวดที่กำลังทำอยู่ แล้วค้นคำที่เจอในล็อกหรือหน้าจอ

  • ชื่อไทยอยู่หน้า คำอังกฤษตามหลังตัวเอียง
  • บรรทัดเขียวคือความหมายบน DGX Spark เครื่องนี้
  • ค้นด้านซ้าย เช่น พิมพ์ KV LoRA 404 NVFP4

Local AI คืออะไร

Local AI on-device / self-hosted AI
รันโมเดลบนเครื่องตัวเอง ไม่ส่งข้อความไปคลาวด์ของบริษัทอื่น ข้อดีคือข้อมูลไม่ออกนอกบ้าน ข้อแลกคือต้องมีเครื่องแรงและจัดการไฟล์เอง

เครื่องนี้คือสตูดิโอ Local ทั้งแชท เอเจนต์ ภาพ วิดีโอ

อินเทอร์เฟซ inference
การเอาโมเดลที่ฝึกแล้วมาตอบ ไม่ใช่การฝึกใหม่ คำว่า inference จึงแปลว่างานใช้งานจริง เช่น แชทหรือสร้างภาพ
ฝึกโมเดล training / fine-tune
การสอนน้ำหนักใหม่จากข้อมูล Training เต็มก้อนแพงมาก Fine-tune คือสอนต่อจากโมเดลสำเร็จรูป LoRA คือวิธี fine-tune ที่เบากว่า
น้ำหนักโมเดล weights
ตัวเลขที่โมเดลเรียนรู้ไว้ เก็บเป็นไฟล์ใหญ่ เช่น .safetensors เปิดโมเดลคือโหลดน้ำหนักขึ้นหน่วยความจำ
พารามิเตอร์ parameters / 7B 27B 35B
จำนวนตัวเลขในโมเดล 27B คือประมาณ 2.7 หมื่นล้านตัว ยิ่งมากยิ่งฉลาดได้และยิ่งกินแรม

บนเครื่องนี้มี Nemotron 30B-A3B, Qwen 27B, Qwen 35B-A3B

เปิดโมเดล load / serve
เอาไฟล์จากดิสก์ขึ้น RAM/GPU แล้วเปิด API ให้โปรแกรมอื่นเรียก ยังไม่ได้แปลว่ากำลังคุย
ปิดโมเดล unload / stop
เอาโปรเซสออกจากหน่วยความจำ เพื่อคืนแรม ไม่ได้ลบไฟล์บนดิสก์

ใช้ stop-model ไม่ใช่ลบโฟลเดอร์ Hugging Face

ออฟไลน์ offline / air-gapped
ทำงานโดยไม่ต้องมีเน็ต ถ้าไฟล์โมเดลมีครบแล้ว

คอนเทนเนอร์ vLLM ตั้ง HF_HUB_OFFLINE=1 จะไม่พยายามดาวน์โหลดซ้ำ

คลาวด์ AI hosted API
ส่งคำขอไปเซิร์ฟเวอร์คนอื่น เช่น OpenAI Claude Gemini ต่างจาก Local ที่คำนวณในบ้าน
OpenAI-compatible OpenAI API schema
รูปแบบคำขอมาตรฐาน /v1/models และ /v1/chat/completions โปรแกรมแชทส่วนใหญ่คุยภาษานี้

vLLM บนพอร์ต 8000 เสิร์ฟแบบนี้ Open WebUI และ Hermes ต่อเข้าจุดเดียวกัน

Anthropic Messages API
รูปแบบคำขอที่ Claude Code ใช้ จุดหลักคือ /v1/messages ไม่ใช่ /v1/chat/completions

vLLM 0.27.1 บนเครื่องนี้พูดภาษานี้ที่พอร์ตเดียวกัน

ฮาร์ดแวร์และหน่วยความจำ

DGX Spark NVIDIA GB10
เวิร์กสเตชัน AI ของ NVIDIA ชิป GB10 รวมซีพียูกับจีพียู ใช้หน่วยความจำก้อนเดียว

เครื่องนี้ชื่อ spark-48c3 มีประมาณ 121 GiB

หน่วยความจำรวม unified memory
แรมระบบกับแรมจีพียูเป็นก้อนเดียวกัน ไม่มี VRAM แยก การ์ดจอโน้ตบุ๊กทั่วไปไม่ใช่แบบนี้

เลขใน free -h รวมของโมเดลด้วย

VRAM video memory
แรมของการ์ดจอแยก บนเครื่องรวมแบบนี้คำนี้มักหมายถึงส่วนที่จีพียูจองจากก้อนเดียวกัน
RAM ที่ใช้ used
คอลัมน์ใน free -h ที่ถูกจองแล้ว รวมแคชของระบบด้วย อย่าดูแค่ช่องนี้
RAM ที่ใช้ได้ available
ตัวเลขที่บอกว่าเปิดโปรแกรมอื่นได้อีกเท่าไร รวมส่วนที่ระบบยอมคืนจากแคช

อ่านคอลัมน์นี้หลังเปิดโมเดล

บัฟเฟอร์และแคช buff/cache
ลินุกซ์เก็บไฟล์ที่เพิ่งอ่านไว้ในแรม ดูเหมือนเต็ม แต่คืนให้โปรแกรมได้เมื่อต้องการ
การจองล่วงหน้า reservation / gpu-memory-utilization
vLLM กันสัดส่วนหน่วยความจำตั้งแต่สตาร์ท สำหรับน้ำหนักบวก KV cache ไม่ได้รอให้คุยยาวแล้วค่อยขอ

Qwen35 ใช้ 0.35 · Qwen27 ใช้ 0.50 · Nemotron ใช้ 0.60 ที่บริบท 500k

GiB / GB
GiB คูณ 1024, GB คูณ 1000 เครื่องนี้โชว์ GiB ใน free -h ประมาณ 121
CUDA
ชุดคำสั่งให้โปรแกรมใช้จีพียู NVIDIA ได้ ถ้า CUDA ไม่ขึ้น โมเดลจะช้าหรือไม่ขึ้นเลย
Tensor Core
วงจรในจีพียู NVIDIA สำหรับคูณเมทริกซ์ของโมเดล AI ควอนไทซ์อย่าง NVFP4 ออกแบบมาใช้ส่วนนี้
NVLink / สายเชื่อมจีพียู
สายเร็วระหว่างจีพียูหลายใบ เครื่องใบเดียวอย่าง Spark ไม่ต้องยุ่ง
Swap
พื้นที่ดิสก์ที่ระบบยืมเมื่อแรมเต็ม ช้ามาก ถ้าเห็น swap ถูกใช้เยอะตอนเปิดโมเดล แปลว่าจองสูงเกิน
OOM out of memory
หน่วยความจำไม่พอ โปรเซสถูกฆ่าหรือสตาร์ทไม่ขึ้น
thermal / อุณหภูมิ
จีพียูร้อนแล้วลดความเร็วเอง งานวิดีโอยาวอาจช้าลงโดยไม่พัง

ควอนไทซ์

ควอนไทซ์ quantization
ลดความละเอียดตัวเลขของน้ำหนัก เพื่อให้ไฟล์เล็กลงและกินแรมน้อย แลกกับความแม่นที่อาจลดเล็กน้อย
FP16 / BF16
ทศนิยม 16 บิต คุณภาพสูง กินแรมประมาณสองเท่าของ 8 บิต
FP8
8 บิตแบบทศนิยม ใช้ทั้งน้ำหนักและ KV cache ได้

สูตร vLLM ตั้ง --kv-cache-dtype fp8

INT8 / INT4 / Q4_K_M
จำนวนเต็ม 8 หรือ 4 บิต ที่พบบ่อยใน GGUF ชื่อ Q4_K_M คือสูตร 4 บิตแบบหนึ่ง
NVFP4
ควอนไทซ์ 4 บิตของ NVIDIA สำหรับชิปใหม่ ไฟล์เล็ก เร็วบน Spark

โมเดลหลักบนเครื่องนี้เป็น NVFP4 เกือบทั้งหมด

ModelOpt
ชุดเครื่องมือควอนไทซ์ของ NVIDIA ที่ vLLM ใช้ถอด NVFP4

Qwen สูตรนี้ใส่ --quantization modelopt

AWQ / GPTQ / GGUF quant
วิธีควอนไทซ์คนละสำนัก อย่าปนไฟล์คนละวิธีในสูตรเดียวกัน
ความแม่น perplexity / quality drop
ควอนไทซ์แรงเกิน โมเดลจะลืมรายละเอียดหรือตอบเพี้ยน
